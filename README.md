# 倍速メーカー

Finderで選んだ動画を倍速にし、「1.25倍速」「3倍速」などのラベルを映像に入れてMP4に保存する、macOS用のアプリです。映像と音声の処理にはmacOS標準のAVFoundationを使います。

## 使い方

1. Finderで動画を1本右クリックし、「このアプリケーションで開く」→「倍速メーカー」を選びます。
2. 1.25倍〜10倍の14種類から再生速度を選びます。
3. 右側の9か所からラベルの位置を選びます。プレビュー上のクリックやドラッグでも調整できます。
4. 「MP4を書き出す」を押して保存先を指定します。元動画とは別のファイルに保存されます。

## ビルドとインストール

macOS 15以降と、Swiftコンパイラを含むXcodeまたはCommand Line Toolsが必要です。Apple Silicon Macで動作を確認済みです。

```sh
./build.sh
```

ビルド後、`build/倍速メーカー.app` をFinderで「アプリケーション」に移動し、一度起動してください。動画の右クリックメニューから倍速メーカーを選べるようになります。

## ソース

- `Sources/App.swift` はFinderからのファイル受け取りと編集画面を担当します。
- `Sources/Video.swift` は動画の読み込み、倍率の適用、ラベルの描画、MP4書き出しを担当します。
- `Sources/Info.plist` にFinderで開ける動画形式を登録しています。
